---
name: evidence-matrix
description: Build or update a proof matrix for disputed factual propositions. Give each a stable ID, the best record evidence on each side and a specific gap to close. Preserve IDs and edits when new exhibits arrive, including in an existing Workbench chronology.
---

Identify counsel's decision and the propositions material to it. Use the attorney's issue list when supplied. If no governing elements are provided, organize by factual issues and flag legal elements for research. Inventory the files you could actually read, including any missing pages, attachments, OCR problems or partial productions that affect coverage.

For a proof matrix, give each proposition a stable ID. Pair its best support and strongest contrary evidence with exhibit and pinpoint. Preserve the difference between a contemporaneous observation, a later account, an allegation, and an inference. End each unresolved row with the specific record or witness that could resolve it. For a chronology, use one row per event and give event date, document date where materially different, actor, event, pinpoint and uncertainty. Keep conflicting dates visible.

Use the locator a second lawyer will see in the original. Prefer stamped Bates numbers, printed transcript page and lines, message IDs, contract sections or ledger entry IDs. Label a PDF viewer page explicitly when it is the only locator. Give a date range or “date unknown” when the source is imprecise. Link multiple copies of the same email to one event so apparent corroboration does not depend on duplicates.

Return a sortable file if requested. Preserve IDs and counsel's edits across revisions. When counsel adds a production, reopen affected originals and report added, revised and withdrawn propositions. Identify the specific dependent figure, draft paragraph or examination question counsel should change.
