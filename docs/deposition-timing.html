How to check the next outline

Read each consequential question aloud. State the relationship the witness would concede merely by answering it. Find the words or timestamps that establish that relationship. Check the follow-ups and counsel notes the same way. A witness’s answer can establish a premise that was open when the deposition began.

For a material unsupported premise, the revised grader withholds full source-fidelity credit and quotes the offending words. For a question that fairly asks which event came first, full credit remains available. Reusable source-fidelity grading guidance · Updated deposition skill.

Test design and materials

We committed the assignment, eight control passages, answer key, new skill language and scoring rules before running the models. Each skill version received three fresh local Codex chats with the same packet, model (GPT-6.1 Sol), high reasoning effort and output instructions. Each chat explicitly selected the corresponding skill file. We retained all six completed outlines, shuffled their labels and audited their questions, follow-ups and notes against the fixed key before opening the version mapping.

For the separate grading test, GPT-6 Astra and GPT-6.1 Sol each scored the same eight passages in two fresh chats at high effort. One chat used the original source-fidelity criterion. The other added the new guidance. The two models saw reverse orders, with order held constant within each model. Each judged four seeded defects and four clean controls without the answer key. Neither counts as an attorney reviewer.
