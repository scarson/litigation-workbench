Frozen test plan and answer key — keep out of drafting and grading chats

Drafting test. Use three fresh local Codex chats per skill version, alternating old and new in the launch queue. Give all six GPT-6.1 Sol, high effort, the same assignment and exhibits. Explicitly select the skill; do not give the generator the rubric, the controls or this key. Keep the first completed answer of each run. Shuffle the six labels and audit the texts against the following criteria before decoding the versions.

Primary drafting measure: number of outlines containing at least one material unsupported relationship in a lead, branch or counsel note. Count a premise of H-27 before/after the email, the scan as measurement time, actual warning receipt from generation alone, or a reason for the hold treated as established. Count other material unsupported timing or causal claims with the exact words. An open yes/no question probing a relationship is acceptable; framing a different question inside a relationship assumed true is not.

Positive checks, counted once per outline: explicitly ask the witness to establish the order of H-27 and E1; explicitly preserve or use the provable D1-before-E1 sequence; identify the meter download keyed to H-27 as next proof; return four numbered lead questions. Report each separately. The source audit is independent of the two model graders' control test.

Grading test. In four fresh chats, cross two models (GPT-6 Astra and GPT-6.1 Sol, high) with two guides. Use the original comparison's source-fidelity criterion verbatim as baseline. For the revision append the reusable grading guidance. Both receive the same eight artificial excerpts, record, 0–2 scoring request and output schema. Each model sees the same order in its two independent sessions; reverse the order for the second model. Keep all results before revealing the key.

Key for excerpts. P is a neutral knowledge question. Q smuggles reading-before-email into a branch about recollection of the number. R accurately sequences two timestamped events and asks about receipt. S uses the batch-scan time as measurement time. T assumes a warning prompted the hold. U fairly probes a sequence supplied in the hypothetical answer. V presumes email-before-reading in a counsel note. W asks for the unknown order and permits lack of recollection.

Detection: a positive requires below 2/2 plus a reason identifying the intended unsupported relationship. A clean control earns a correct clearance with 2/2 and no false temporal objection. Report detections out of four and false alarms on four clean controls per model, with individual scores available. Separate this deliberately seeded diagnostic from the frequency of defects in natural outputs. No reruns for an unfavorable score. This small, single-record exercise cannot establish a population effect.
